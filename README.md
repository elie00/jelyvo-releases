# Jelyvo — Releases

Dépôt de distribution de **Jelyvo**, lecteur YouTube Music pour Android.

Ce dépôt n'héberge que les APK signés et les notes de version. Il est lu par
l'application elle-même pour proposer les mises à jour automatiques.

## Installer

Télécharger le dernier APK : [Releases → Latest](https://github.com/elie00/jelyvo-releases/releases/latest)

À la première installation, Android demande d'autoriser l'installation depuis
des sources inconnues. Les mises à jour suivantes sont proposées directement
dans l'application.
